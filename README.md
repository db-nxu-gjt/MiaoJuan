# 妙卷

**教师智能组卷工具** —— 基于题库的 AI 智能试卷生成 Android 应用。

## 功能特性

- **智能组卷**：按科目、章节、题型、难度一键生成试卷
- **手动组卷**：自由选题、调整题序与分值
- **题库管理**：题目录入、分类与检索
- **试卷导出**：导出 Word / PDF，可直接打印使用
- **试卷分享**：一键分享到微信等常用平台
- **额度体系**：免费用户每日 3 次生成；会员套餐与次数包灵活组合

## 下载安装

1. 前往 [Releases](../../releases) 页面下载最新版 APK
2. 手机上点击安装，首次安装需允许「安装未知来源应用」
3. 打开「妙卷」→ 注册账号 → 登录使用（服务器地址已内嵌，无需配置）

> 建议通过本页 Releases 下载，或直接在 App 内「发现新版本」弹窗中升级。

## 常见问题

**Q：安装时提示"未知来源"？**
在系统设置中允许该来源安装，或安装时选择「仍要安装」。

**Q：升级后提示签名不一致无法安装？**
请先卸载旧版再安装新版（仅 v1.0.0 → v1.1.0 需要，之后版本可直接覆盖升级）。

**Q：生成次数用完了？**
可在「会员中心」购买次数包（永久有效）或开通会员套餐。
